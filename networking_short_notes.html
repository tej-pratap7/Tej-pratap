Topic 01 · Error Control
CRC — Cyclic Redundancy Check
The "Digital Seal" on your data
🎯 Remember It Like a wax seal on a courier box — if the seal is broken, data was tampered.
  • 1Sender adds CRC bits at the end of the message before sending.
  • 2Receiver divides received data by Generator. If remainder = 000, data is safe ✅
  • 3Uses Modulo-2 Division (XOR). Same bits = 0, Different bits = 1.
  • 4Best for detecting burst errors (many consecutive bit flips).
  • 5Used in Ethernet, Wi-Fi, Bluetooth.
Steps (Exam Formula) 1. Message poly → Binary
2. Append zeros (= degree of G(x))
3. XOR divide by Generator
4. Remainder = CRC
5. Transmitted = Message + CRC
💡 M(x)=x⁷+x⁵+1 → 10100001

Topic 02 · Flow Control
Windowing + Go-Back-N
Don't drown the receiver!
🎯 Remember It Like throwing 3 balls at once — wait for catch confirmation before throwing 3 more. Window = how many balls at once.
  • WWindow Size = max frames sender can send without waiting for ACK.
  • FCFlow Control: Receiver shrinks window size if it's getting overwhelmed.
  • RReliability: If no ACK comes in time → Timer expires → Retransmit.
GO-BACK-N RULE Frame lost? → Receiver discards ALL frames after the lost one.
Sender goes BACK and retransmits from the lost frame onward.
Receiver only accepts IN-ORDER frames.
💡 N=3 → Frame 1 lost → Resend F1, F2, F3

Topic 03 · Routing
Distance Vector Routing (DVR)
Ask your neighbors, not the whole map
🎯 Remember It Like asking your neighbor for directions. You don't know the whole city, just who's next door.
  • 1Each router knows only its direct neighbors + their distances.
  • 2Periodically shares its entire table with neighbors.
  • 3Uses Bellman-Ford: New cost = (My cost to neighbor) + (Neighbor's cost to dest).
  • 4If new cost < old cost → Update the table.
COUNT-TO-INFINITY PROBLEM Link B→C breaks. B sets C = ∞.
But A still says "I can reach C in 2!"
B believes A → sets C = 3. A updates to 4. B to 5...
Counts to ∞ (=16 in RIP) before realizing C is dead.

Topic 05 · Transport Layer
TCP 3-Way Handshake — Connection Setup & Teardown
Like a phone call — say Hello before talking
🎯 Remember It "Can you hear me?" → "Yes, can you hear me?" → "Yes! Let's talk." = SYN → SYN-ACK → ACK
CONNECTION (3 STEPS)
  • SSYN: Client → Server. "Hi, my seq = X."
  • SASYN-ACK: Server → Client. "Got it (ACK=X+1). My seq = Y."
  • AACK: Client → Server. "Got it (ACK=Y+1). Let's go!"
💡 States: CLOSED → SYN-SENT → SYN-RECEIVED → ESTABLISHED
TERMINATION (4 STEPS)
  • FFIN: Client → "I'm done sending."
  • AACK: Server → "Okay, noted."
  • FFIN: Server → "I'm done too."
  • AACK: Client → "Bye!" → CLOSED.
💡 Connection = 3 steps. Termination = 4 steps.

Topic 06 · Security
MD5 — Message Digest Algorithm
The "fingerprint" of your data
🎯 Remember It Like a mixer/grinder — any input gives fixed output. You can't get fruits back from juice!
  • !Any input → always 128-bit fixed output (hash / digest).
  • !One-way: Cannot reverse the hash to get original data.
  • !Used for: data integrity + password storage.
5 STEPS (MEMORIZE ORDER) Step 1: Pad bits (add 1, then 0s → make length = 448 mod 512)
Step 2: Append 64-bit length of original message
Step 3: Init 4 buffers: A, B, C, D (32-bit each = 128 bits total)
Step 4: Process 512-bit blocks — 4 rounds × 16 ops = 64 ops
Step 5: Concat A+B+C+D = 128-bit MD5 hash 🎯

Topic 07 · IP Addressing
IPv6 — Features & Transition
10-digit phone numbers for the internet
🎯 Remember It IPv4 = 5-digit phone numbers (ran out). IPv6 = 10-digit (infinite supply).
  • +128-bit address (2¹²⁸ addresses = almost infinite).
  • +IPsec built-in: Security is mandatory, not optional.
  • +Simpler header: Checksum removed → Routers process faster.
  • +No NAT needed: Every device gets its own global IP.
TRANSITION METHODS Dual Stack = device runs BOTH IPv4 & IPv6 simultaneously (hybrid car 🚗⚡)
Tunneling = IPv6 packet hidden inside IPv4 packet to cross IPv4 network (truck inside a truck 🚚)
Fragmentation: IPv4 = routers fragment. IPv6 = only sender fragments (routers drop & notify).

Topic 09 · Modulation
FSK & PSK — Digital Modulation
Converting 0s & 1s into waves
🎯 Remember It FSK = change whistle pitch (high=1, low=0). PSK = change dance step direction (flip=1, same=0).
  • FSKFrequency changes. High freq = 1, Low freq = 0. Used in: Caller ID, old modems.
  • PSKPhase changes (180° shift when bit changes). Used in: Wi-Fi, Bluetooth.
PSK PROBLEM + SOLUTION Problem (Phase Ambiguity): Receiver doesn't know original reference phase → can't decode 0 or 1.

Solution → DPSK (Differential PSK):
Same bit as previous → No phase change (0°)
Different bit → Phase shifts 180°
Receiver compares current vs previous — no absolute reference needed! ✅
